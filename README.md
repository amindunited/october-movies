# October Movie Night

Spin the shelf, pick a case, and discover a classic horror movie.

[Visit October Movie Night](https://amindunited.github.io/october-movies/)

The movie list and details are stored in [`movies.json`](./movies.json).

## Local development

With Python 3 installed, run:

```sh
npm run dev
```

Then open <http://localhost:8000>. The server binds to localhost and serves the site files directly.
